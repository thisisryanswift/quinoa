# Define release, versioning, security, and contributor policy

Define the repository's release process and ownership documents before adding automated publishing or broad contributor workflows.

## Design

Resolve Python/Rust version synchronization, changelog expectations, vulnerability reporting, contribution workflow, packaging targets, and release authorization boundaries. Keep public writes human-gated.

## Acceptance Criteria

A reviewed policy states version source of truth, release/checklist and rollback, changelog handling, security reporting, contributor expectations, and explicitly authorized publication steps without enabling a release automatically.
